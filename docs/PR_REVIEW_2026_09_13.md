# Pull request review — 2026-09-13

This record covers the 58 open PRs from the review inventory (86–145, excluding
90 and 115). PR titles and green checks were not treated as proof of correctness.
Each proposed source/doc diff was inspected; runtime validation is scoped below.

## Disposition

- 39 proposals closed without merging, with individual technical explanations.
- 19 proposals retained through [integration PR #147](https://github.com/CodeinScrubs/BidiLens/pull/147):
  16 corrected/supplemented contributions plus the reviewed changes from 87, 88
  and 89. The original 16 small PRs were closed as superseded, not merged as-is.
- The integration PR is the authoritative merge/check record. The dependency
  updates and hardening changes are tested together against current `main`;
  branch protection is not bypassed to merge stale individual candidates.
- No registry publication is part of this review. Unreleased APIs are marked.

The consolidation preserves existing default direction policy, LTR
non-interference and host alignment. It adds no global font, page-direction,
chart-layout, editor or clipboard policy. Public security allowlists stay private.
The source inputs from 12 small test PRs are consolidated into 47 candidate
fixtures, plus seven LTR controls, with source identity, offset and finalized
stream checks. They are not native-speaker-reviewed or UAX #9 conformance tests.
The invented project domain in one fixture was replaced with example.com.
